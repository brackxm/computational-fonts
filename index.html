The font does the work.

OpenType substitutions, ligatures, and glyph composition turn the input text into the result you see. The playgrounds provide controls and prepare text for the font; the computation happens during text shaping.

Read about the project →
Can I try these in a document?

Most projects include an editable ODT specimen with embedded fonts. Open it in LibreOffice Writer and change the examples. Look for the document link in the demo or project folder. WebAssembly provides a browser playground and a command-line runtime.

What happens when I copy a result?

The result is made of glyphs. Copying it preserves the original input text, rather than the computed appearance. These are experimental fonts with documented limits; rendering can vary between applications.
