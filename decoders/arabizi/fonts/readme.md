`NotoNaskhArabic[wght].ttf` in the official Google Fonts repository:

- Source revision: [`ad2e6647e3d97ad5a8b6b5f95042f99161af5915`](https://github.com/google/fonts/tree/ad2e6647e3d97ad5a8b6b5f95042f99161af5915/ofl/notonaskharabic).

The build uses a weight-400 instance to derive Latin annotations, Arabic joining
forms and common-word outlines. The derivative is named **Arabizi Annotated**
and distributed under OFL 1.1, with upstream attribution preserved.
