# Roboto 2 font sources

These unmodified fonts come from the official Roboto 2 repository at tag
**v2.138**. Decoder builders use Regular by default; the Markdown-style
formatter also uses the bold and italic styles.
Their embedded font version is `Version 2.001047; 2015`; the repository tag
pins the source revision rather than changing that metadata.

Generated computational fonts retain Google's original attribution and Apache
license metadata. Their copyright and description fields identify Michael
Brackx's modifications. They receive distinct family names.

Builds add glyphs and shaping rules; the bundled source files are kept
unchanged. Fonts built from original geometric outlines do not use Roboto.
