# Roboto 2 decoder base

`Roboto-Regular.ttf` is the unmodified file from the official Roboto 2
repository at tag **v2.138**. All decoder builders use it by default.
Its embedded font version is `Version 2.001047; 2015`; the repository tag
pins the source revision rather than changing that metadata.

- [Upstream font](https://github.com/googlefonts/roboto-2/blob/v2.138/src/hinted/Roboto-Regular.ttf)
- [Upstream license](https://github.com/googlefonts/roboto-2/blob/v2.138/LICENSE)
- License: Apache License 2.0; see [LICENSE](LICENSE).
- Copyright 2015 Google Inc. All Rights Reserved.
- Roboto is a trademark of Google.
- SHA-256: `56a45233d29f11b4dfb86d248e921939d115778f87325e7ae8cc108383d6664d`

Generated decoder fonts retain Google's original attribution and Apache
license metadata. Their copyright and description fields identify Michael
Brackx's decoder modifications. They receive distinct decoder font names.

The decoder builds add glyphs and shaping rules; this bundled base is kept
unchanged. Both Snake fonts use original geometric outlines independently.
