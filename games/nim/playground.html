Nim

Take any positive number of tokens from one heap. In normal play, taking the last token wins; in misère play, it loses. The font plays both versions perfectly and computes the displayed XOR itself.

New game settings
Three heaps, 0–31 tokens each

At least one starting token is required. The default is a forced font win. Try 1, 1, 1 in misère mode with the font first: you can beat its perfect play from that losing start.

The binary columns show each heap’s size. The gold XOR row is calculated inside the font from the current heaps. A zero XOR is a losing normal-play position. Misère play needs a different rule when only one large heap, or just single tokens, remains.

A header such as bN03,05,07; selects font-first normal play; hM01,03,05; selects human-first misère. Append only your takes: A02;, B01;, or C04;. Always use two digits. Spaces and line breaks are allowed; a finished game ignores trailing input. JavaScript passes text and reads the font’s status.
