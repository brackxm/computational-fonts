Backgammon SGF replay

Paste a linear backgammon record. The font reads the SGF, moves the checkers, infers hits, and draws the final position. JavaScript supplies the input and reads the font’s completion signal.

White uses ivory rings; Black uses solid dark checkers. Each occupied point shows its exact count, with up to five checkers drawn. Point numbers are White’s 1–24; letters A–X label SGF’s lowercase coordinates. Separate counters show each player’s bar and borne-off checkers. The dice show the latest roll and player.

Prototype subset: one linear tree, the standard starting position, optional root GM[6], FF[4], and CA[UTF-8], then one W[...] or B[...] per node. Up to 128 turns, including rolls with no movement. Spaces are insignificant. Move values contain two dice digits and zero to four coordinate pairs.

Replay completion reports that explicit transfers were applied. It does not establish legality: dice usage, movement distance and direction, bar-entry priority, and bearing-off rules are not validated. Variations, comments, setup positions, match metadata, cube actions, and pip counts are unsupported.
