Wythoff’s Nim

Take any positive number of tokens from one heap, or the same number from both. Whoever takes the last tokens wins. The font plays perfectly, using the exact golden-ratio strategy.

Each heap can start at 0–63, with at least one token overall. The default position is a forced win for the font. Try starting at 21 and 34 with the font first: that is a losing position, so you can beat perfect play by finding the right replies.

A header such as b31,47; makes the font move first; h31,47; makes you move first. Append only your moves: A03; takes three from A, B02; takes two from B, and D04; takes four from each. Always use two digits. Spaces and line breaks are allowed. A finished game ignores trailing input.

The font checks every move, updates both heaps, chooses its replies, and draws the tokens. JavaScript supplies text and reads the font’s status.
