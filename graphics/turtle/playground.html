F moves one cell. L / R turn 90°. U / D lift or lower the pen. A filled triangle means pen down; a hollow triangle means pen up. An X marks the canvas boundary.

Choose a pen color with 0–5 or the buttons. New strokes use that color; existing strokes keep theirs. The turtle marker shows the active color. Color changes count toward the command limit.

Type commands above or use the buttons and keyboard. Spaces, line breaks, and uppercase are accepted. The font evaluates up to 128 commands in one text run. Undo restores the previous drawing.
