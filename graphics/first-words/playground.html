How it works and what it supports

The input is passed to the font unchanged. OpenType standard ligatures (liga) recognize words and substitute picture glyphs. COLR/CPAL tables supply vector colour layers, including the outlines converted from the original SVGs. JavaScript does not replace words with images.

Alternate names and listed plurals share the same picture: try sofa / couch, bike / bicycle, fridge / refrigerator, or tooth / teeth. Search either name in the word picker. Spaced labels also accept hyphenated or joined spellings. Compounds need a single ordinary or non-breaking space and consistent formatting; some applications split shaping at spaces or formatting boundaries. Download every accepted spelling and its drawing.

Adjacent letters, digits, combining marks, underscores, apostrophes and hyphens block a partial match within the same shaping run. Thus cat is a picture while caterpillar and cat's remain text. Punctuation such as commas and parentheses can surround a picture word.

Countable plural words show two diagonally stacked copies, with the same width as a single picture. Irregular plurals such as mice and teeth work too. Grouped drawings, uncountable words, and ambiguous forms such as fish and sheep retain their existing picture.

Colour needs COLRv0 font support. Applications without it can use the font's monochrome outline drawings. In an installed font, the same word substitutions work when standard ligatures are enabled. Different applications can shape and export fonts differently.
