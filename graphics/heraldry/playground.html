The vocabulary, and how it works

Seven tinctures

Or · gold
Argent · silver
Azure · blue
Gules · red
Sable · black
Vert · green
Purpure · purple

Fields

Solid, per pale, per fess, per bend, per bend sinister, per chevron, per saltire, quarterly.

Divided fields take two tinctures joined by “and”.

Ordinaries

Chief, fess, pale, bend, bend sinister, chevron, cross, saltire, bordure.

One ordinary per shield.

Charges

Mullet, lozenge, crescent, heart, fleur-de-lis, lion rampant.

One centred charge, or three arranged two above one.

This is a deliberately small blazon grammar. Each word accepts lowercase, an initial capital or UPPERCASE; use one to three spaces between words. An optional comma separates the field and device. No furs, counterchanging, additional charge groups, or arbitrary natural-language descriptions are supported. Colour combinations are rendered without enforcing the rule of tincture.

The source text is passed to the font unchanged. OpenType ligatures recognise complete bracketed descriptions, select field and device glyphs, and compose their colour layers. These previews are actual font text. Selecting the preview selects its full source; “Copy blazon” copies it exactly, including its spacing. JavaScript updates the text, editor controls and clipboard. Switch rendering off to see the original letters.

Install the TTF and enable standard ligatures to use it in another application. Keep each description in one font/style run with normal letter spacing. Colour needs COLRv0 support; the monochrome fallback shows outlines and divisions without identifying tinctures. Spaced ligatures vary by application; this playground uses browser page text.
