P3, width and height, 3 for maxval, then three samples per pixel in red, green, blue order. Each sample is 0–3; 3 0 0 is red and 3 3 3 is white. Each dimension is 1–32. Separate every sample with whitespace. Colors use evenly spaced sRGB channel values.

The page removes # comments and folds whitespace for a single shaping run. It accepts up to 8,192 source characters. Extra pixels and trailing data are rejected. The preview reserves a 32 × 32 canvas.
