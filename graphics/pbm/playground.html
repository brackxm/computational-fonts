A text image drawn by an OpenType font. The font reads the dimensions, checks the pixels and renders the bitmap.

P1, width and height, then pixels: 0 is white and 1 is black. Each dimension is 1–64. Pixels run left to right, top to bottom; spaces between bits are optional.

The page removes # comments and folds whitespace for a single shaping run. It accepts up to 16,384 source characters. Extra pixels and trailing data are rejected. The preview reserves a 64 × 64 canvas.
