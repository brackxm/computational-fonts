Write a small BASIC program. OpenType rules inside the font execute assignments, arithmetic, branches, loops and subroutines, then draw the output and final variables.

Number lines from 1–99 in increasing order. Variables A–D hold 0–99. Use +, -, *, / or MOD, with one operator per expression.

Up to 16 statements, 128 executed instructions, eight output rows and 24 characters per output row. PRINT joins up to four strings or expressions with semicolons. IF and WHILE accept two comparisons joined by AND or OR, with optional NOT before either comparison. IF may include ELSE with a second jump target. Division returns an integer. FOR uses constant bounds and an optional nonzero STEP from −99 to 99. Negative steps count down; variables stay within 0–99. WHILE/WEND retests its condition before each iteration; one loop may be active at a time. GOSUB/RETURN supports four call levels, sharing variables A–D. The page supplies source text; the font performs parsing and execution.
