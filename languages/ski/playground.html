Three rules. A language in a font.

Write an expression using S, K, I and lowercase atoms. OpenType rules inside the font select reductions, duplicate subtrees, and draw the resulting expression. Evaluation follows normal order within a fixed tree and reduction budget.

I x → xK x y → xS x y z → x z (y z)

Application associates left: S K K a means ((S K) K) a. Use parentheses for compound arguments, or explicit prefix syntax such as @@@SKKa.
