Computational fonts · WebAssembly

WebAssembly, shaped by a font.

Choose a compiled program and change its arguments. OpenType substitutions inside the font compute the result in one shaping call, including arithmetic, branches, bounded loops and memory.

Use decimal, hexadecimal (0x), or binary (0b), with an optional minus sign. Arguments wrap to their declared 32 or 64 bits.

Results show the same bits as unsigned, signed and hexadecimal integers. A trap or execution bound has no valid result. Disable font computation to check that unfinished registers are rejected.

These examples are already compiled into fonts. To edit a program, compile its WAT or Wasm with build.py and load the resulting pair below.




Load your own compiled program
  
Build a font and its ABI manifest:

  
python3 languages/wasm/build.py program.wat --export run -o program.ttf

  
  
  
Files stay in this browser. The page verifies that the font matches its manifest before running it. Every invocation starts with fresh memory and globals.

The bundled HarfBuzz engine runs in a worker. JavaScript encodes arguments and reads the shaped glyph registers; it does not execute the example's Wasm module. Fonts use invisible machine glyphs, so ordinary text rendering does not display their results.
